## Notes

### FEFO/Expiry Status

The PharmFlow application (v0.6.0+7) implements FEFO (First-Expired, First-Out) logic within its business engine (`fefo_allocation_service.dart`). When adding products to the cart, the system automatically selects the batch with the nearest expiry date. The FEFO-related captures show navigation through the application's existing screens (Dashboard, Inventory) which display inventory information. A dedicated FEFO/expiry management screen with a separate tab has not been identified in the current build.

### Video Capture Method

Videos captured using ffmpeg gdigrab at 15fps, 1550x830 resolution, H.264 (CRF 26).

### Staging Area

All assets are staged in `_hermes-output/` for review before integration into `public/`. See `mapping-proposal.md` for the proposed integration plan.
